## Smaller PDF attachments

> I built PDFEnrich for everyday PDF tasks. If a PDF attachment is too large, try the free compression tool: https://pdfenrich.com/compress-pdf. No account or payment is required. It shows the actual size change and a preview; results depend on the file. Start with lossless or balanced compression. Review the output before sending it, especially if you choose maximum reduction.

Supporting instructions: https://pdfenrich.com/guides/compress-pdf-for-email

## One PDF instead of several attachments

> Need to combine several PDFs into one attachment? I built a free browser tool that lets you choose the files, arrange them, and download a merged PDF without creating an account: https://pdfenrich.com/merge-pdf. Check the page order before sending the result. Feedback on a specific problem is welcome.

Supporting instructions: https://pdfenrich.com/guides/how-to-combine-pdf-files

## Release checks and measurement

- Check upload, processing, and downloaded output on desktop Chromium, Android Chromium, and iPhone WebKit. Include reload/reopen for the editor.
- Compression checks cover smaller output, retained searchable text and forms in balanced mode, batch ZIP re-download, and honest larger-output handling. These are fixture-based checks, not guarantees for every PDF.
- Merge checks cover page count; manually review page order and appearance for the example you share.
- Use existing consent-aware analytics to compare visits to each task with upload, successful processing, and completed-download events. Do not equate sign-ins with usage: both workflows intentionally allow guests.
- Separate your own testing from customer activity. Do not put filenames, PDF content, email addresses, or document identifiers into analytics or campaign links.
- Record the channel and date of each approved post. Compare real completed workflows before expanding promotion. Traffic and search rankings are not guaranteed.
